## How to Be Listed

We recognize contributions in several ways:

### Code Contributions
- Submit a pull request that gets merged
- Automatically listed here and in GitHub contributors
- Credited in release notes

- Fix typos or improve clarity
- Add translations (future)

- Help answer questions in discussions
- Report bugs with detailed information
- Suggest improvements and features
- Help other users in issues

### Recognition Criteria

To be listed as a contributor, you need to:

1. **Make a meaningful contribution** (not just typo fixes, unless substantial)

3. **Have your contribution accepted/merged**

## Becoming a Maintainer

Exceptional contributors may be invited to become maintainers:

- **Reliability** - Consistent availability and responsiveness

- Review and merge pull requests

- Guide project direction
- Mentor new contributors

## Contribution Guidelines

### Quick Start for New Contributors

1. **Find an Issue**
   - Browse [open issues](https://github.com/Mostafa-SAID7/bloggingAgent/issues)
   - Look for `good first issue` label
   - Check if anyone is already working on it

2. **Fork and Clone**
   ```bash
   git clone https://github.com/yourusername/bloggingAgent.git
   cd bloggingAgent
   ```

3. **Create Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Changes**
   - Follow our [coding standards](CONTRIBUTING.md#styleguides)
   - Add tests for new features
   - Update documentation as needed

5. **Submit PR**
   - Fill out the PR template
   - Link related issues
   - Wait for review

### Need Help?

Don't hesitate to ask for help:
- Comment on the issue you're working on
- Join GitHub discussions
- Read our documentation
- Check existing PRs for examples
